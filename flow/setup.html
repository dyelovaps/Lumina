Google Flow dans Lumina

Lumina regroupe Grok et la connexion Chrome de FlowKit. Il suffit de charger une seule extension : Lumina. Si l’extension FlowKit est déjà installée, désactivez-la pour éviter deux connexions concurrentes.

Ce qui est intégré

L’onglet Google Flow permet d’ouvrir Flow, d’activer la connexion au service local et de suivre ses requêtes. Les formulaires Grok continuent d’envoyer leurs lots uniquement à Grok. Les projets et générations Flow se pilotent avec le tableau de bord ou l’API de FlowKit.

Service local nécessaire

FlowKit utilise Python 3.10 ou plus. Son tableau de bord utilise Node.js et npm. FFmpeg est nécessaire pour les opérations d’assemblage. Cette page fournit les commandes ; Lumina n’installe et ne démarre pas ces programmes.

Dans PowerShell, depuis le dossier où vous souhaitez installer le service :

git clone https://github.com/crisng95/flowkit.git flowkit-local
cd flowkit-local
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

Ouvrez Google Flow, connectez-vous et créez un projet. Copiez son identifiant depuis l’adresse du projet. Dans le même terminal, remplacez la valeur ci-dessous puis démarrez le service :

$env:FLOW_PROJECT_ID = "identifiant-du-projet-flow"
.\.venv\Scripts\python.exe -m agent.main

Gardez ce terminal et l’onglet Flow ouverts. Dans Lumina → Google Flow, activez la connexion. L’état doit indiquer Service local connecté. Cela confirme la connexion au service, pas encore la réussite d’une génération.

Tableau de bord des projets et générations

Dans un second terminal, depuis le dossier du service :

cd dashboard
npm install
npm run dev

Ouvrez le tableau de bord local. Il remplace l’utilisation manuelle de l’API pour les opérations qu’il expose.

En cas de connexion impossible

  • Vérifiez que le terminal du service reste ouvert sans erreur.
  • Le service HTTP utilise le port 8100 et la connexion extension le port 9222.
  • Vérifiez votre connexion à Google Flow et l’identifiant du projet.
  • Rechargez Lumina dans chrome://extensions puis actualisez l’onglet Google Flow.

Intégration fondée sur FlowKit, révision 57b52e6375ac7034848c13da461838a6f7545aca. Les générations réelles nécessitent un compte Google Flow et les capacités disponibles sur ce compte. Les commandes Windows ci-dessus n’ont pas été exécutées automatiquement.
