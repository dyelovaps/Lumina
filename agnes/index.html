Traitement par lot

Un bloc par plan : le numéro, puis une ligne IMAGE : et/ou une ligne VIDÉO :. Ajoutez RÉF : Léa, Marc pour choisir les références du plan (sinon, les noms de la Bibliothèque cités dans le prompt sont repris). Formats acceptés aussi : « 01 IMAGE : … », tableau Markdown (N° | Image | Vidéo | Réf), CSV, JSON.

Déjà faites ailleurs (ChatGPT, Midjourney…) ? Nommez-les 01.png, 02.png… : chacune est animée avec le prompt VIDÉO de son numéro, sans générer d'image. 05a.png + 05b.png = plan début + fin.

Réglages API

La clé est enregistrée uniquement dans ce navigateur et n'est envoyée qu'à l'API configurée ci-dessous.

Agnes attend des URL publiques pour Image → Image, Image → Vidéo, frames et ingrédients. Avec cette clé, vos images locales sont mises en ligne automatiquement. Sans elle, l'image est envoyée intégrée (data URL), ce que certaines API refusent.
